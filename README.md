### Hi, I'm Florent !

Business Mathematics student at the University of Mannheim. Still learning, already building.

I built **[Quantitative-Portfolio-Optimizer](https://github.com/FlorentYigbe/Quantitative-Portfolio-Optimizer)**, a Python-based multi-asset portfolio optimization engine spanning equities, fixed income, and commodities, and **[VaR-CVaR-Simulator](https://github.com/FlorentYigbe/VaR-CVaR-Simulator)**, a risk simulation tool for portfolio tail-risk analysis.

I'm currently running a live paper-trading portfolio on Interactive Brokers using allocations generated by my own optimization models.

⚡ **Fun fact**: I'm just as passionate about literature as I'm about quantitative finance !
